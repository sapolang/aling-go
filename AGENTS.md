# AGENTS.md

## Quick commands

- `make dev` / `wails3 dev` — development mode (hot reload)
- `make build` / `wails3 build` — production build
- `make vet` — `go vet ./...`
- `make test` — `cd frontend && npx tsc --noEmit`
- `make tidy` — `go mod tidy && cd frontend && npm install`
- `make clean` — remove build artifacts
- `wails3 generate bindings` — regenerate frontend Go bindings (output in `frontend/bindings/`, gitignored)

## Architecture

- **Wails v3** (`v3.0.0-alpha2.119` in `go.mod`). README says v2 — stale.
- **7 service structs** in root `*_service.go` files, each registered via `application.NewService()` in `main.go`.
- `main.go` → init 3 SQLite DBs → `application.New()` → register 7 services → `Run()`
- DB init & migration happen in `main.go` before `application.New()`, not in `ServiceStartup`.
- All Go ↔ frontend data exchange uses manual `json.Marshal`/`json.Unmarshal` on JSON strings.

| `platform_service.go` | `NewPlatformService(app)` | no |

| `article_service.go` | `NewArticleService(app)` | no |
| `dict_service.go` | `NewDictService(app)` | no |

| `whisper_service.go` | `NewWhisperService(app, dataDir)` | yes |

## Data layer

- Three SQLite databases in `os.UserConfigDir()/aling-go/`:
  - `userData.db` — words, tags, SRS, typing progress (`var db *sql.DB`)
  - `articles.db` — read-only articles/categories (`var articleDB *sql.DB`)
  - `dict.db` — read-only dictionary (`internal/dict/`, `var dictDB *sql.DB`)
- `db` and `articleDB` are globals in `package main`; `dictDB`/`userDB` are globals in `internal/dict`
- Media library uses `library.json` (not SQLite) stored in the config dir

## Bindings gotcha

Bindings are `.ts` files generated by `wails3 generate bindings` into `frontend/bindings/` (gitignored). The bridge imports from flat paths like `../../bindings/aling-go/wordservice`. If service package structure changes (e.g. moved to `internal/`), binding paths change and `frontend/src/api/bridge.ts` must be updated.

## Gotchas

- `findFFmpeg` and `extractAudio` in `ffmpeg.go` are package-level, shared by `MediaService` and `WhisperService`
- `bundleResources()` in `whisper_service.go` called by `findFFmpeg` (macOS .app bundle path resolution)
- `wails3` CLI must be installed separately: `go install github.com/wailsapp/wails/v3/cmd/wails3@latest`
- No Go unit tests exist yet
- No frontend linter (no eslint/prettier config), no golangci-lint config
- `.task/` directory is build cache (gitignored), created by Wails internal task runner
